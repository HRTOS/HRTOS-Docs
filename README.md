# HRTOS Docs

**HRTOS 官方技术文档仓库**

HRTOS Docs 是 HRTOS 实时操作系统的官方文档仓库，集中维护系统开发手册、API 参考、内核设计说明、应用示例、扩展模块文档、常见问题及 PDF 发布版本，为系统学习、应用开发、工程集成和技术维护提供完整的文档支持。

HRTOS 面向经典及增强型 8051（MCS-51）单片机，围绕实时任务调度、任务管理、时间管理、任务间通信、同步机制、中断处理、资源管理及嵌入式应用开发构建完整的操作系统体系。

项目坚持以实际工程需求为导向，持续完善内核功能、接口文档、应用示例和配套组件，致力于为 8051 嵌入式开发提供结构清晰、功能完整、便于理解和持续维护的操作系统解决方案。

## 项目简介

HRTOS（Hard Real-Time Operating System）是一款面向 8051 单片机的实时操作系统，采用实时任务调度机制，支持多任务并发管理及常见的实时系统服务。

HRTOS 不仅关注操作系统内核本身，也重视从内核接口到应用开发的完整工程体系，涵盖任务调度、同步与通信、定时服务、中断协作、扩展模块、驱动组件及实际应用示例。

项目的主要特点包括：

- **完整的任务管理与调度体系**：支持任务创建、管理、状态转换、优先级调度及任务切换等功能。
- **系统化的实时服务**：提供时间管理、延时与等待、事件、信号量、互斥锁、邮箱和消息队列等机制。
- **面向 8051 的系统设计**：针对 MCS-51 系列处理器的存储空间、寄存器组、中断机制及编译环境进行设计与适配。
- **完善的内核设计文档**：从内核启动、任务状态机、调度器到同步机制、内存布局和移植层，系统说明关键设计与实现思路。
- **丰富的扩展模块**：提供 Coop、MyOS、Shell 和 Modbus 等相关模块的文档。
- **面向实际应用的组件资料**：涵盖基础控制、显示、传感器、控制设备和数据存储等应用方向。
- **持续维护的技术资料**：通过 Markdown 源文件和 PDF 发布文档，支持内容更新、版本管理及离线阅读。

## 文档使用指南

根据不同的开发目标，可以选择相应的阅读路径。

**初次接触 HRTOS**

建议从《HRTOS 快速入门指南》和《HRTOS 使用入门》开始，了解基本配置、系统启动、任务创建及基本应用流程。

**进行应用程序开发**

建议先阅读系统使用手册，再查阅 `api/` 中对应的 API 文档，并结合 `Application/` 中的应用示例进行开发。

**深入理解内核**

建议从 `system/00_README.md` 和 `system/01_kernel_overview.md` 开始，逐步阅读任务管理、调度、同步通信、定时系统、中断设计和内存布局等文档。

**使用扩展模块**

根据需求阅读 `extensions/` 中的模块说明，并结合对应 API、配置要求和示例进行集成。

**离线学习或技术归档**

可以使用 `pdf/` 目录中的 PDF 文档，进行完整阅读、打印、归档或工程资料交付。

## 项目定位

HRTOS 不仅是一个任务调度内核，也是一套面向 8051 嵌入式开发的完整操作系统及配套技术体系。

项目围绕操作系统内核、实时服务、API 接口、扩展模块、驱动组件、应用示例和技术文档持续建设，注重系统功能的完整性、实现的可理解性以及工程应用中的可维护性。

对于资源受限的 8 位微控制器，操作系统的价值不仅在于代码规模，还在于如何组织任务、管理资源、协调中断、提供统一的软件接口，并为实际应用建立清晰、可持续维护的软件结构。

HRTOS 致力于在经典 8051 平台上持续完善这一完整体系，为嵌入式开发者提供稳定、清晰且具有工程实用价值的技术基础。
