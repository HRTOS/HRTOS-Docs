# 邮箱模块

## 模块简介

邮箱模块提供单字节消息传递机制，适合简单的信号通知和数据传递。HRTOS 邮箱采用统一资源模型实现，支持任务间快速通信。

### 设计目的

- 提供简单的单字节消息传递
- 支持任务间快速通信
- 实现事件通知机制
- 采用统一资源模型管理

### 使用场景

- 简单信号通知
- 单字节数据传递
- 事件标志传递
- 任务同步

## 数据类型

本模块使用 config.h 中定义的 OS_RESOURCE 结构。

## 宏定义

本模块无公开宏定义。

## API 函数列表

| 函数名称 | 功能说明 |
|---|---|
| os_mailbox_init | 邮箱初始化 |
| os_mailbox_send | 邮箱发送 |
| os_mailbox_receive | 邮箱接收 |
| os_mailbox_query | 邮箱查询 |
| os_mailbox_clear | 邮箱清除 |

## API 详细说明

### os_mailbox_init

函数原型：

```c
void os_mailbox_init(u8 mid);
```

参数说明：

| 参数 | 类型 | 说明 |
|---|---|---|
| mid | u8 | 邮箱 ID（资源对象编号） |

返回值：

无

功能说明：

初始化指定邮箱。函数会：

1. 检查邮箱 ID 是否合法
2. 清空邮箱内容（value = 0）
3. 清空资源拥有者（owner = OS_INVALID_ID）
4. 清空等待队列（wait_mask）
5. 清空等待计数（wait_cnt）

邮箱采用统一资源模型：
- value：邮箱数据（0=空，非0=有数据）
- wait_mask：等待该邮箱的任务位图

调用示例：

```c
os_mailbox_init(0);  // 初始化邮箱 0
```

注意事项：

- 邮箱 ID 必须在 0 到 OS_RESOURCE_MAX-1 范围内
- 初始化应在系统启动或单任务环境调用
- 初始化后邮箱为空

### os_mailbox_send

函数原型：

```c
char os_mailbox_send(u8 mid, u8 content);
```

参数说明：

| 参数 | 类型 | 说明 |
|---|---|---|
| mid | u8 | 邮箱 ID |
| content | u8 | 待发送数据 |

返回值：

- 1：发送成功
- -1：参数错误

功能说明：

向指定邮箱发送一个字节数据。

**有等待接收任务时：**
- 写入数据（m->value = content）
- 查找等待队列中的任务
- 调用 wake_task() 唤醒任务
- 返回 1

**无等待任务时：**
- 写入数据（m->value = content）
- 数据保存在邮箱中
- 返回 1

邮箱语义：
- 写入数据
- 如果有等待接收任务，直接唤醒
- 否则保存数据供后续接收

调用示例：

```c
char result = os_mailbox_send(0, 0x55);
if (result == 1) {
    // 发送成功
}
```

注意事项：

- 邮箱只能保存一个字节数据
- 新数据会覆盖旧数据
- 支持中断安全版本 os_queue_send_from_isr
- 可能触发任务调度

### os_mailbox_receive

函数原型：

```c
int os_mailbox_receive(u8 mid);
```

参数说明：

| 参数 | 类型 | 说明 |
|---|---|---|
| mid | u8 | 邮箱 ID |

返回值：

- 接收到的数据（非负数）
- -1：参数错误

功能说明：

从指定邮箱接收一个字节数据。

**邮箱有数据时（快路径）：**
- 读取数据（_data = m->value）
- 清空邮箱（m->value = 0）
- 返回数据

**邮箱无数据时（慢路径）：**
- 调用 os_wait(WAIT_MAILBOX, mid, 0) 进入等待
- 被唤醒后重新读取数据
- 返回数据

邮箱语义：
- 如果有数据，直接取走
- 如果无数据，进入等待状态

调用示例：

```c
int data = os_mailbox_receive(0);
if (data >= 0) {
    // 接收成功，data 包含接收到的数据
}
```

注意事项：

- 接收后邮箱变为空
- 可能阻塞当前任务
- 多次接收会等待新数据
- 返回值为 int 类型，需检查是否为 -1

### os_mailbox_query

函数原型：

```c
int os_mailbox_query(u8 mid);
```

参数说明：

| 参数 | 类型 | 说明 |
|---|---|---|
| mid | u8 | 邮箱 ID |

返回值：

- 邮箱中的数据（非阻塞查询）
- -1：参数错误

功能说明：

非阻塞查询指定邮箱中的数据。不会改变邮箱状态，也不会阻塞当前任务。

调用示例：

```c
int data = os_mailbox_query(0);
if (data >= 0) {
    // 邮箱中有数据
}
```

注意事项：

- 非阻塞操作
- 不会清空邮箱
- 不会触发任务调度
- 适合轮询场景

### os_mailbox_clear

函数原型：

```c
char os_mailbox_clear(u8 mid);
```

参数说明：

| 参数 | 类型 | 说明 |
|---|---|---|
| mid | u8 | 邮箱 ID |

返回值：

- 清除结果

功能说明：

清除指定邮箱中的数据，重置邮箱为空状态。

调用示例：

```c
char result = os_mailbox_clear(0);
```

注意事项：

- 会丢弃邮箱中的数据
- 不会唤醒等待任务
- 谨慎使用，可能导致数据丢失
