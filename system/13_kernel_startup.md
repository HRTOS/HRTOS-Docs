# HRTOS 内核启动

## 模块介绍

内核启动负责完成 HRTOS 从系统复位到进入运行状态的初始化过程。

启动流程主要包括：

-   清理系统运行环境
-   初始化内核数据区域
-   配置系统参数
-   创建系统基础任务
-   启动 Timer0 系统时基
-   进入空闲任务
-   等待中断触发调度

HRTOS 当前启动流程基于 8051
架构设计，系统初始化完成后首先进入空闲任务，由定时器中断和任务调度机制驱动后续运行。

## 启动流程概述

系统启动过程：

``` text
系统复位
    ↓
main()
    ↓
清理内部 RAM
    ↓
初始化内核数据区
    ↓
设置系统参数
    ↓
创建空闲任务
    ↓
创建系统中断任务
    ↓
初始化任务栈
    ↓
启动 Timer0
    ↓
开启中断
    ↓
进入 os_idle_task()
    ↓
等待调度运行用户任务
```

## 系统入口

### main()

HRTOS 启动入口为用户工程中的 `main()` 函数。

主要职责：

-   清理 MCU 初始状态
-   初始化 HRTOS 内核变量
-   创建系统任务
-   配置系统定时器
-   开启中断
-   进入空闲任务

## 内存初始化

### 内部 RAM 清理

系统启动首先清理 8051 内部 RAM。

目的：

-   保证变量初始状态确定
-   避免复位后的随机数据影响系统运行

典型流程：

``` text
设置地址指针
    ↓
清零累加器
    ↓
循环清除内部 RAM
```

### 内核数据区初始化

内部 RAM 初始化完成后，清理 HRTOS 使用的数据区域。

包括：

-   任务状态
-   调度变量
-   IPC 资源
-   系统计数器

## 内核参数初始化

启动过程中需要设置核心运行参数。

主要包括：

### 当前任务

``` c
OS_CURRENT_TASK = 0;
```

系统初始运行任务编号为 0。

### 系统模式

``` c
OS_RTOS_YES = 1;
```

表示启用 RTOS 调度模式。

### 调度状态

初始化：

-   调度原因
-   中断状态
-   时间片计数

### Tick 计数器

初始化系统运行时间统计：

-   低 16 位计数器
-   高 16 位计数器

用于记录系统运行时间。

## 系统任务创建

### 空闲任务

系统首先创建空闲任务：

``` c
os_task_create(os_idle_task, 0, 0, 2);
```

空闲任务负责：

-   系统入口
-   空闲处理
-   任务资源清理

### 系统中断任务

创建系统保留任务：

-   中断退出处理任务
-   高优先级中断相关任务

用于支持系统内部调度流程。

## 定时器初始化

### Timer0 配置

HRTOS 使用 Timer0 作为系统时间基准。

初始化内容：

-   设置重载值
-   配置工作模式
-   开启 Timer0 中断
-   启动定时器

示例：

``` c
TMOD |= 0x01;
ET0 = 1;
TR0 = 1;
```

Timer0 负责：

-   系统 Tick
-   时间片管理
-   调度触发

## 进入空闲任务

完成初始化后：

``` c
os_idle_task();
```

系统正式进入 RTOS 运行状态。

空闲任务是 HRTOS 启动后的第一个执行任务。

其职责：

-   完成运行阶段初始化
-   调用用户初始化入口
-   执行空闲循环

## 空闲任务运行流程

``` text
进入 os_idle_task
    ↓
初始化运行状态
    ↓
调用 hrtos_main()
    ↓
用户创建应用任务
    ↓
开启系统运行
    ↓
进入空闲循环
```

## hrtos_main()

### 作用

`hrtos_main()` 是用户应用初始化入口。

用于：

-   创建用户任务
-   初始化 IPC
-   配置应用模块
-   完成启动阶段配置

示例：

``` c
void hrtos_main(void)
{
    os_task_create(task1, ...);
    os_task_create(task2, ...);

    os_sem_init(...);
}
```

### 注意事项

`hrtos_main()` 应：

-   不执行长时间阻塞操作
-   不进行无限循环
-   快速完成初始化

## 调度启动

系统启动完成后：

1.  Timer0 产生系统中断
2.  内核更新 Tick
3.  判断是否需要调度
4.  选择最高优先级任务
5.  完成任务切换

任务开始正式运行。

## 启动阶段划分

### 硬件初始化阶段

主要工作：

-   CPU 复位
-   RAM 清理
-   基础寄存器初始化

### 内核初始化阶段

主要工作：

-   初始化内核变量
-   初始化任务环境
-   初始化资源

### 系统启动阶段

主要工作：

-   创建系统任务
-   启动 Timer0
-   开启中断

### 运行阶段

主要工作：

-   空闲任务运行
-   Timer0 驱动调度
-   用户任务执行

## 启动约束

启动过程中：

-   初始化期间避免中断干扰
-   任务创建需要在系统启动阶段完成
-   Timer0 配置必须正确
-   用户初始化不能长时间占用 CPU

## 启动调试

### 系统无法运行

检查：

-   main 是否正常执行
-   RAM 初始化是否完成
-   Timer0 是否启动
-   总中断是否开启

### 用户任务不执行

检查：

-   任务创建返回值
-   任务优先级
-   任务状态
-   调度是否触发

### 系统异常复位

检查：

-   栈空间
-   内存越界
-   中断嵌套
-   用户任务运行时间

## 总结

HRTOS 启动过程采用简单明确的初始化流程：

硬件环境准备 → 内核初始化 → 创建基础任务 → 启动定时器 → 进入空闲任务 →
调度运行。

该设计保持启动过程可控、结构清晰，符合轻量级 8051 实时系统的设计目标。
